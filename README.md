# nxgntch Reference Documentation

This repository contains historical and reference documentation that's not needed during runtime startup.

## Contents

- **docs/archive/** - Historical documentation from completed phases
- **skills/planning/** - Planning and design documents for skill development

## Usage

Clone this alongside nxgntch/it for offline reference. It's automatically synced during CI builds but not loaded at startup to reduce initialization overhead.

See nxgntch/it/CLAUDE.md for active documentation.
