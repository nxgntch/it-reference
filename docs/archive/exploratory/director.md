# Director Agent

**Model**: claude-haiku-4.5 (quick tier)  
**Capabilities**: Task routing, orchestration, team synthesis, cost analysis

The Director agent serves as the top-level orchestrator in the nxgntch system. It routes tasks to appropriate teams (Engineering, Research) and synthesizes results across teams.

- Task normalization and validation
- Team and specialist routing
- Cross-team result synthesis
- Cost-aware model selection
